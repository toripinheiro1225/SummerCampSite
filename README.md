## Local Preview (optional)

From this folder, run:

```powershell
npx serve .
```

Then open the local URL shown in terminal.

## Deploy to Vercel (no coding needed)

1. Create a free account at https://vercel.com/ and sign in with GitHub.
2. Put this folder in a GitHub repo (or include it inside an existing repo).
3. In Vercel, click **Add New... > Project**.
4. Import the repo and select this folder as the root directory if prompted.
5. Leave build settings empty (it is a static site) and deploy.
6. Vercel gives you a shareable URL like `your-project-name.vercel.app`.
